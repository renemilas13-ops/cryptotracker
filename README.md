# CryptoTracker CLI
Real-time crypto portfolio tracker za Termux.
## Install
git clone https://github.com/renemilas13-ops/cryptotracker.git
cd cryptotracker && pip install requests && python3 main.py
## Features
- Real-time prices (CoinGecko API)
- Add/delete cryptos
- Profit/Loss calc
## Tech
Python 3, JSON, Termux
